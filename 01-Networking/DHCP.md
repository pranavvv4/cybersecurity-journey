# 🌐 DHCP

DHCP (Dynamic Host Configuration Protocol) automatically provides network configuration to devices.

## Examples

When a device connects to a network, DHCP can provide:

- IP address
- Subnet mask
- Default gateway
- DNS server

## Characteristics

- Automatically configures network settings
- Uses UDP
- Server uses port `67`
- Client uses port `68`
- Avoids manually configuring IP addresses

## Key Takeaway

**DHCP = Automatically provides network configuration to devices.**
