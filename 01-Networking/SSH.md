# 🔐 SSH

SSH (Secure Shell) is a protocol used for secure remote access to systems.

## Examples

```text
SSH → TCP Port 22
```

A user can connect to a remote Linux server using SSH.

## Characteristics

- Uses TCP
- Default port is `22`
- Encrypts communication
- Supports password authentication
- Supports key-based authentication

## Key Takeaway

**SSH = Secure and encrypted remote access.**
