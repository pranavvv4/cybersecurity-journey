# 🔄 NAT

NAT (Network Address Translation) translates private IP addresses into public IP addresses when devices communicate with the Internet.

## Examples

A home device:

```text
192.168.1.10 → Router (NAT) → Public IP → Internet
```

## Characteristics

- Commonly performed by routers/firewalls
- Allows private IP addresses to access the Internet
- Translates between private and public IP addresses
- Helps conserve IPv4 addresses
- Common in home and enterprise networks

## Key Takeaway

**NAT → Translates private IP addresses to public IP addresses for network communication.**
