# 📡 Telnet

Telnet is a protocol used for remote access to systems and network services.

## Examples

```text
Telnet → TCP Port 23
```

A user can connect to a remote Telnet service through a command-line interface.

## Characteristics

- Uses TCP
- Default port is `23`
- Communication is not encrypted by default
- Older remote-access protocol
- SSH is commonly used instead for secure remote access

## Key Takeaway

**Telnet = Remote access protocol that sends communication without encryption by default.**
