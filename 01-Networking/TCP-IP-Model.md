# 🌐 TCP/IP Model

The **TCP/IP Model** is a networking model used to describe how devices communicate over networks.

## 4 Layers

| Layer | Name | Examples |
|---:|---|---|
| 4 | Application | HTTP, DNS, SSH |
| 3 | Transport | TCP, UDP |
| 2 | Internet | IP, ICMP |
| 1 | Network Access | Ethernet, Wi-Fi |

## Layers

### 4. Application

Provides network services to applications.

Examples:
- HTTP
- DNS
- SSH
- FTP

### 3. Transport

Provides communication between applications.

Examples:
- TCP
- UDP

### 2. Internet

Handles logical addressing and routing.

Examples:
- IPv4
- IPv6
- ICMP

### 1. Network Access

Handles communication over the physical/local network.

Examples:
- Ethernet
- Wi-Fi
- MAC addresses

## OSI vs TCP/IP

| OSI | TCP/IP |
|---|---|
| 7 layers | 4 layers |
| Application | Application |
| Presentation | Application |
| Session | Application |
| Transport | Transport |
| Network | Internet |
| Data Link | Network Access |
| Physical | Network Access |

## Key Takeaway

**OSI = 7-layer reference model**

**TCP/IP = 4-layer practical networking model**
