# 🌐 OSI Model

The **OSI (Open Systems Interconnection) Model** is a 7-layer model used to understand how network communication works.

## 7 Layers

| Layer | Name | Examples |
|---:|---|---|
| 7 | Application | HTTP, DNS, FTP |
| 6 | Presentation | Encryption, encoding |
| 5 | Session | Session management |
| 4 | Transport | TCP, UDP |
| 3 | Network | IP, Routers |
| 2 | Data Link | Ethernet, MAC |
| 1 | Physical | Cables, radio signals |

## Layers

### 7. Application
Provides network services directly to applications.

Examples:
- HTTP
- DNS
- FTP

### 6. Presentation
Handles data formatting, encoding, and encryption.

### 5. Session
Establishes, manages, and terminates communication sessions.

### 4. Transport
Provides end-to-end communication.

Examples:
- TCP
- UDP

### 3. Network
Handles logical addressing and routing.

Example:
- IP

### 2. Data Link
Handles local network communication and frames.

Examples:
- Ethernet
- MAC addresses

### 1. Physical
Transmits raw bits through physical or wireless media.

Examples:
- Ethernet cables
- Fiber
- Radio signals

## Key Takeaway

Remember the layers from **Layer 7 → Layer 1**:

**Application → Presentation → Session → Transport → Network → Data Link → Physical**
