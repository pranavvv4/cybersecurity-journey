# 🚪 Default Gateway

A default gateway is the device that forwards traffic from a local network to other networks.

## Examples

A computer may have:

```text
IP Address:      192.168.1.10
Default Gateway: 192.168.1.1
```

When accessing a device outside the local network:

```text
Computer → Default Gateway → Other Network
```

## Characteristics

- Usually the local router's IP address
- Used to reach other networks
- Required for communication outside the local subnet
- Works at the Network Layer
- Commonly used with routers

## Key Takeaway

**Default Gateway → The device used to reach other networks.**
