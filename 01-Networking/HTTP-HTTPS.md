# 🌐 HTTP and HTTPS

HTTP is a protocol used to transfer web data between a client and a server.

HTTPS is the secure version of HTTP that uses encryption.

## Examples

```text
HTTP  → Port 80
HTTPS → Port 443
```

## Characteristics

### HTTP

- Uses TCP port `80`
- Data is not encrypted by HTTP itself
- Used for web communication

### HTTPS

- Uses TCP port `443`
- Uses TLS encryption
- Protects data during transmission

## Key Takeaway

- **HTTP → Web communication**
- **HTTPS → Encrypted web communication**
