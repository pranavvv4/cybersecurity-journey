# 🔗 MAC Addresses

A MAC address is a unique address assigned to a network interface. It is mainly used for communication within a local network.

## Format

A MAC address is usually written in hexadecimal.

Example:

00:1A:2B:3C:4D:5E

## Characteristics

- Works at Layer 2 of the OSI model
- Used for local network communication
- Associated with a network interface
- Usually represented by 48 bits

## MAC Address vs IP Address

| MAC Address | IP Address |
|---|---|
| Physical/link-layer address | Logical address |
| Layer 2 | Layer 3 |
| Used mainly in local networks | Used for network communication |

## What I Learned

A MAC address identifies a network interface at the local network level, while an IP address is used for logical network communication.
