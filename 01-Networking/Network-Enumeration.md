# 🔎 Network Enumeration

Network enumeration is the process of gathering information about a target system or network.

## Examples

Information that can be discovered:

- Open ports
- Running services
- Service versions
- Operating system information
- Network details

## Characteristics

- Helps identify exposed services
- Usually performed after discovering a target
- Can be performed using automated tools
- Nmap is a commonly used enumeration tool

## Common Command

```bash
nmap <TARGET_IP>
```

## Key Takeaway

**Network enumeration = Gathering information about systems, services, and networks.**
