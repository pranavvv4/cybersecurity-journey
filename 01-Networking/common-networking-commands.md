# 💻 Common Networking Commands

Common networking commands are used to view, test, and troubleshoot network connections.

## Examples

### Ping

Tests connectivity between devices.

```bash
ping <TARGET_IP>
```

### Ipconfig

Displays network configuration on Windows.

```cmd
ipconfig
```

### Ifconfig / Ip

Displays network interfaces and IP information on Linux.

```bash
ip addr
```

### Netstat

Displays network connections and listening ports.

```bash
netstat -ano
```

### Traceroute / Tracert

Shows the path packets take to a destination.

```bash
tracert <TARGET_IP>
```

Linux:

```bash
traceroute <TARGET_IP>
```

## Characteristics

- `ping` → Tests connectivity
- `ipconfig` → Shows Windows network configuration
- `ip addr` → Shows Linux network interfaces
- `netstat` → Shows connections and listening ports
- `tracert` / `traceroute` → Shows the network path

## Key Takeaway

**Networking commands → Help identify, test, and troubleshoot network connectivity and services.**
