# 🧱 Firewall

A firewall is a security system that monitors and controls network traffic based on defined rules.

## Examples

A firewall can allow or block traffic:

```text
Internet → Firewall → Internal Network
```

Example rule:

```text
Allow TCP 443
Block TCP 23
```

## Characteristics

- Controls incoming and outgoing traffic
- Uses rules to allow or block traffic
- Can filter by IP addresses, ports, and protocols
- Can be hardware-based or software-based
- Helps protect networks from unauthorized access

## Key Takeaway

**Firewall → Controls network traffic using security rules.**
