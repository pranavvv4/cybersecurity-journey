# 🔐 TLS

TLS (Transport Layer Security) is a cryptographic protocol used to secure network communication.

## Examples

HTTPS uses TLS to protect web traffic:

```text
Client → TLS Connection → Web Server
          🔒 Encrypted
```

Common examples:

- HTTPS
- Secure email
- Secure application communication

## Characteristics

- Encrypts data in transit
- Helps provide confidentiality
- Helps verify the identity of servers using certificates
- Helps protect data from tampering
- TLS is used by HTTPS

## Key Takeaway

**TLS → Protects network communication using encryption, authentication, and integrity.**
