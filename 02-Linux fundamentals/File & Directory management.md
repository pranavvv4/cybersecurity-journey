# 📂 Linux File & Directory Management

Linux provides commands to create, view, search, copy, move, and delete files and directories.

## Examples

Create a directory:

```bash
mkdir test
```

Create a file:

```bash
touch file.txt
```

Copy a file:

```bash
cp file.txt backup.txt
```

Move or rename a file:

```bash
mv file.txt newfile.txt
```

Remove a file:

```bash
rm file.txt
```

Search for a file:

```bash
find / -name "file.txt"
```

## Characteristics

- `ls` → List files and directories
- `mkdir` → Create directories
- `touch` → Create files
- `cp` → Copy files/directories
- `mv` → Move or rename
- `rm` → Remove files/directories
- `find` → Search for files and directories

## Key Takeaway

**Linux file management → Create, view, search, copy, move, rename, and remove files and directories.**
