# 🧰 Linux System Information & Monitoring

Linux provides commands to inspect system information, resource usage, and running activity.

## Examples

View system information:

```bash
uname -a
```

View memory usage:

```bash
free -h
```

View disk usage:

```bash
df -h
```

View running processes:

```bash
ps aux
```

View CPU and process activity:

```bash
top
```

## Characteristics

- `uname` → Shows system and kernel information
- `free` → Shows memory usage
- `df` → Shows disk space usage
- `ps` → Shows running processes
- `top` → Provides real-time process monitoring
- Useful for troubleshooting and security investigations

## Key Takeaway

**Linux system monitoring → Helps understand system resources, processes, and operating-system activity.**
