# 🐧 Linux Fundamentals

Linux is an open-source operating system widely used in servers, cloud environments, and cybersecurity.

## Examples

Common Linux commands:

```bash
pwd
ls
cd
mkdir
cp
mv
rm
cat
less
grep
find
```

## Characteristics

- Command-line focused
- Uses a hierarchical file system
- Supports users and permissions
- Widely used in servers and cloud environments
- Provides powerful networking and system administration tools
- Commonly used in cybersecurity

## File System

Important directories:

```text
/       → Root directory
/home   → User directories
/etc    → Configuration files
/var    → Variable data and logs
/tmp    → Temporary files
/usr    → User programs and utilities
```

## Key Takeaway

**Linux → A major operating system and essential foundation for cybersecurity and security engineering.**
