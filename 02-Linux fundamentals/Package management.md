# 📦 Linux Package Management

Linux package managers are used to install, update, remove, and manage software packages.

## Examples

On Debian/Ubuntu/Kali:

```bash
sudo apt update
sudo apt install nmap
sudo apt remove nmap
```

Search for a package:

```bash
apt search nmap
```

## Characteristics

- `apt update` → Updates package information
- `apt install` → Installs software
- `apt remove` → Removes software
- `apt search` → Searches for packages
- Package managers handle software dependencies
- Different Linux distributions use different package managers

## Key Takeaway

**Package management → Install, update, search, and remove Linux software and its dependencies.**
