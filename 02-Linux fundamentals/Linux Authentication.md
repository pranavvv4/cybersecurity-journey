# 🔐 Linux Authentication

Linux authentication verifies the identity of users before allowing access to the system.

## Examples

Check the current user:

```bash
whoami
```

View logged-in users:

```bash
who
```

View login history:

```bash
last
```

Change your password:

```bash
passwd
```

## Characteristics

- Verifies user identity
- Commonly uses usernames and passwords
- SSH can use password or SSH-key authentication
- Authentication events can be recorded in system logs
- Authentication is different from authorization

## Key Takeaway

**Linux Authentication → Verifies who is allowed to access a Linux system.**
