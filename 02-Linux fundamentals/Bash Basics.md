# 🔧 Bash Basics

Bash (Bourne Again Shell) is a command-line shell commonly used on Linux systems to execute commands and automate tasks.

## Examples

Run commands:

```bash
echo "Hello"
pwd
ls
```

Use variables:

```bash
name="Kali"
echo $name
```

Use a simple condition:

```bash
if [ -f file.txt ]; then
    echo "File exists"
fi
```

## Characteristics

- Executes commands through the terminal
- Supports variables and conditions
- Supports loops and functions
- Can automate repetitive tasks
- Bash scripts commonly use the `.sh` extension
- Widely used for Linux administration and security automation

## Key Takeaway

**Bash → A Linux shell and scripting language used to execute commands and automate tasks.**
