# 🪟 Windows Fundamentals

Windows is a widely used operating system in desktops, enterprise environments, and corporate networks.

## Examples

Common Windows components:

```text
Windows OS
├── File System
├── Users & Groups
├── Processes & Services
├── Registry
├── Networking
└── Event Logs
```

Useful commands:

```powershell
whoami
ipconfig
tasklist
systeminfo
```

## Characteristics

- Uses users and groups for access control
- Supports NTFS file permissions
- Provides processes and services
- Uses the Windows Registry for system configuration
- Provides built-in networking tools
- Generates security and system event logs

## Key Takeaway

**Windows → An important operating system to understand for enterprise security and Security Engineering.**
