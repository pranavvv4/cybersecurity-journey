# 🔍 Windows System Enumeration

Windows system enumeration is the process of gathering information about a Windows system, its users, processes, services, network configuration, and security settings.

## Examples

View system information:

```powershell
systeminfo
```

View logged-in user:

```powershell
whoami
```

View running processes:

```powershell
Get-Process
```

View services:

```powershell
Get-Service
```

View network configuration:

```powershell
ipconfig /all
```

## Characteristics

- Identifies system and OS information
- Reveals users and groups
- Helps identify running processes and services
- Provides network configuration details
- Useful for system administration and security investigations
- Should be performed only on systems you are authorized to assess

## Key Takeaway

**Windows Enumeration → Gathering system information to understand the Windows environment.**
