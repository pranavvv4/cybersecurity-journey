# 💻 Windows PowerShell

PowerShell is a command-line shell and scripting environment used to manage Windows systems and automate administrative tasks.

## Examples

View running processes:

```powershell
Get-Process
```

View services:

```powershell
Get-Service
```

View network configuration:

```powershell
Get-NetIPConfiguration
```

Search for a file:

```powershell
Get-ChildItem -Path C:\ -Recurse -Filter "file.txt"
```

## Characteristics

- Uses commands called **cmdlets**
- Can manage users, processes, services, files, and networks
- Supports scripting and automation
- Can interact with Windows security features
- Commonly used by system administrators and security professionals

## Key Takeaway

**PowerShell → Windows command-line and scripting environment used for administration, automation, and security tasks.**
