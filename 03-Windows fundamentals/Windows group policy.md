# 📜 Windows Group Policy

Group Policy is a Windows feature used to centrally configure and enforce settings for users and computers in an Active Directory environment.

## Examples

Group Policy can control:

```text
Password Policies
Account Lockout
Windows Firewall
Software Restrictions
Security Settings
```

Open the Local Group Policy Editor:

```text
Win + R → gpedit.msc
```

## Characteristics

- Centrally manages Windows configuration
- Can apply settings to users and computers
- Commonly managed through Active Directory
- Helps enforce security policies
- Can control authentication and access-related settings

## Key Takeaway

**Group Policy → Centrally configures and enforces Windows settings and security policies.**
