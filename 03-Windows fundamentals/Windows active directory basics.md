# 🏢 Windows Active Directory Basics

Active Directory (AD) is a Microsoft directory service used to centrally manage users, computers, groups, and resources in Windows domain environments.

## Examples

A typical domain environment:

```text
Active Directory Domain
        ↓
Domain Controller
   ├── Users
   ├── Groups
   ├── Computers
   └── Policies
```

Common concepts:

```text
Domain → Centralized Windows environment
Domain Controller → Server that manages the domain
User → Account in the domain
Group → Collection of users
GPO → Centralized configuration policies
```

## Characteristics

- Centrally manages users and computers
- Uses domain controllers
- Supports authentication and authorization
- Uses groups to manage permissions
- Group Policy can enforce security settings
- Common in enterprise Windows environments

## Key Takeaway

**Active Directory → Centrally manages identities, computers, permissions, and policies in Windows enterprise networks.**
