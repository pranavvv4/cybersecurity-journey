# 🎯 MITRE ATT&CK — Short Notes

## 📌 Definition
MITRE ATT&CK is a knowledge base of real-world adversary tactics and techniques used to understand attacks and improve security defenses.

## 🔑 Core Concepts
- **Tactics:** Why an attacker performs an action.
- **Techniques:** How an attacker achieves an objective.
- **Procedures:** The specific implementation of a technique.

## 🔍 SOC Applications
- Alert investigation
- Threat hunting
- Detection engineering
- Incident reporting
- Security gap analysis

## 💡 Example
An attacker attempts to dump credentials from a Windows system.

- **Tactic:** Credential Access
- **Technique:** OS Credential Dumping
- **SOC Action:** Investigate process activity, endpoint telemetry, and relevant security logs.

## 🎯 Key Takeaway
MITRE ATT&CK provides a common language for describing attacker behavior and improving security detections.
