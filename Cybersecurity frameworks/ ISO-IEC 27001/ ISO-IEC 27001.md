# ISO/IEC 27001 — Lesson 1

## Definition
ISO/IEC 27001 is an international standard for establishing, implementing, maintaining, and continually improving an Information Security Management System (ISMS).

## What is an ISMS?
An ISMS is a structured system of policies, processes, people, and security controls used to manage information security risks.

## CIA Triad
- **Confidentiality:** Prevent unauthorized access to information.
- **Integrity:** Protect information from unauthorized changes.
- **Availability:** Ensure information and systems are accessible when needed.

## How ISO 27001 Works
1. Identify information security risks.
2. Assess the likelihood and impact of risks.
3. Select and implement suitable security controls.
4. Monitor controls and conduct audits.
5. Continually improve the ISMS.

## Cloud Security Example
A company stores customer data in AWS. It assesses the risk of account compromise and applies MFA, least-privilege IAM permissions, encryption, and logging.

## Key Takeaway
ISO 27001 provides a risk-based management framework for information security. It helps organizations protect information and continually improve their security practices.
