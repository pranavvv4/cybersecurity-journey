# 👨‍💻 SOC Analyst Skills & Responsibilities

## Definition
A SOC Analyst is a cybersecurity professional responsible for monitoring security systems, detecting threats, investigating alerts, and responding to security incidents.

## Examples

### Technical Skills
- **Networking:** Understanding TCP/IP, DNS, HTTP/HTTPS, ports, and protocols.
- **Linux:** Using Linux commands and analyzing system logs.
- **Windows:** Understanding Event Viewer, PowerShell, and Windows security logs.
- **SIEM:** Searching and analyzing logs using tools like Splunk and Microsoft Sentinel.
- **EDR:** Investigating suspicious endpoint activities.
- **Threat Intelligence:** Analyzing malicious IPs, domains, and file hashes.
- **Incident Response:** Understanding containment, eradication, and recovery.
- **Scripting:** Using Python and Bash to automate security tasks.

### Responsibilities
- Monitor security alerts and dashboards.
- Investigate suspicious activities.
- Analyze network and system logs.
- Identify potential security incidents.
- Escalate serious incidents to higher-level teams.
- Document investigation findings.
- Participate in incident response activities.

## Characteristics
- **Analytical Thinking:** Identify patterns and investigate unusual behavior.
- **Problem-Solving:** Understand security issues and find appropriate solutions.
- **Attention to Detail:** Examine logs and alerts carefully.
- **Communication:** Explain findings clearly to team members.
- **Continuous Learning:** Stay updated on new threats and attack techniques.
- **Teamwork:** Coordinate with IT, security, and incident response teams.

## Important Details

### SOC Analyst Levels

| Level | Responsibilities |
|---|---|
| L1 – Tier 1 | Alert monitoring, initial triage, and escalation |
| L2 – Tier 2 | Detailed investigation and incident response |
| L3 – Tier 3 | Advanced threat hunting, detection engineering, and complex investigations |

Responsibilities can vary between organizations.

## Key Takeaway
A SOC Analyst combines networking, operating systems, security tools, investigation techniques, and analytical skills to detect and respond to cyber threats.
