# 🔎 SOC Investigation Process

SOC investigation is the process of examining security alerts, collecting evidence, correlating events, and determining whether suspicious activity represents a security incident.

## Examples

```text
Alert Received
      ↓
Collect Evidence
      ↓
Analyze Logs & Activity
      ↓
Correlate Events
      ↓
Build Timeline
      ↓
Determine Findings
      ↓
Document & Escalate
```

Example:

```text
Event 1 → Multiple failed logins
Event 2 → Successful login from an unusual IP
Event 3 → Unexpected privilege escalation

Finding → Possible account compromise
Action  → Investigate and follow incident response procedures
```

## Characteristics

- **Evidence Collection** → Gather relevant logs, alerts, process details, and network activity
- **Log Analysis** → Examine timestamps, users, IP addresses, and event details
- **Event Correlation** → Connect related events across different systems
- **Timeline Analysis** → Establish the sequence of activities
- **Findings** → Determine what the evidence supports and identify remaining uncertainties
- **Documentation** → Record evidence, conclusions, and actions taken
- **Escalation** → Refer confirmed or complex cases to the appropriate team

## Key Takeaway

**SOC Investigation → Collect evidence, analyze activity, correlate events, establish a timeline, and document findings.**
