# 🛠️ SOC Analyst Tools & Technologies

## Definition
SOC Analyst Tools are security technologies used to monitor systems, detect threats, investigate suspicious activities, and respond to security incidents.

## Examples

- **SIEM:** Splunk, Microsoft Sentinel, IBM QRadar.
- **EDR:** Microsoft Defender for Endpoint, CrowdStrike Falcon, SentinelOne.
- **Network Analysis:** Wireshark, Zeek.
- **IDS/IPS:** Snort, Suricata.
- **Vulnerability Scanning:** Nessus, OpenVAS.
- **Threat Intelligence:** VirusTotal, AbuseIPDB, AlienVault OTX.
- **SOAR:** Cortex XSOAR, Splunk SOAR.
- **Digital Forensics:** Autopsy, Volatility.

## Characteristics

- **Monitoring:** Collects and monitors security events.
- **Detection:** Identifies suspicious activities and potential threats.
- **Investigation:** Helps analysts examine logs, files, and network traffic.
- **Response:** Supports containment and remediation of threats.
- **Automation:** Automates repetitive security tasks.
- **Reporting:** Generates alerts, reports, and investigation records.

## Important Details

| Tool | Main Purpose |
|---|---|
| Splunk | Log analysis and SIEM |
| Microsoft Sentinel | Cloud-based SIEM and SOAR |
| Wireshark | Network packet analysis |
| Zeek | Network security monitoring |
| Snort | Network intrusion detection and prevention |
| Microsoft Defender for Endpoint | Endpoint detection and response |
| VirusTotal | File and URL reputation analysis |
| Nessus | Vulnerability scanning |
| Autopsy | Digital forensic investigation |
| Volatility | Memory forensics |

## Key Takeaway
SOC analysts use multiple security tools together to monitor networks, detect threats, investigate incidents, and protect organizational systems.
