# 🧩 Defense in Depth

Defense in depth is a security strategy that uses multiple layers of protection so that one failed control does not compromise the entire system.

## Examples

A layered security approach:

```text
Internet
   ↓
Firewall
   ↓
Network Segmentation
   ↓
Endpoint Protection
   ↓
Authentication + MFA
   ↓
Access Controls
   ↓
Logging + Monitoring
```

## Characteristics

- Uses multiple security controls
- Prevents dependence on a single security mechanism
- Combines preventive, detective, and corrective controls
- Limits the impact of a successful attack
- Common in enterprise security architectures

## Key Takeaway

**Defense in Depth → Multiple layers of security working together to protect systems and data.**
