# 🌐 Web Application Security

Web application security focuses on protecting websites and web applications from vulnerabilities that could expose data or allow unauthorized actions.

## Examples

Common web application vulnerabilities:

```text
SQL Injection       → Malicious input manipulates database queries
XSS                 → Malicious scripts execute in a user's browser
Broken Access Control → Users access resources they shouldn't
Security Misconfiguration → Unsafe application settings
Authentication Failure → Weaknesses in login or session handling
```

## Characteristics

- **SQL Injection (SQLi)** → Improperly handled input affects database queries
- **Cross-Site Scripting (XSS)** → Untrusted content causes scripts to execute in a browser
- **Broken Access Control** → Users can perform actions beyond their permissions
- **Security Misconfiguration** → Insecure defaults or settings expose systems
- **Authentication Failures** → Weak authentication or session management enables account compromise
- Secure coding, input validation, access checks, and security testing help reduce these risks

## Key Takeaway

**Web Application Security → Protect applications, users, and data from attacks by addressing software and configuration weaknesses.**
