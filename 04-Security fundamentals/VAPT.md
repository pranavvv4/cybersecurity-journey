# 🧪 Vulnerability Assessment & Penetration Testing

Vulnerability Assessment and Penetration Testing (VAPT) are security activities used to identify weaknesses and evaluate the security of systems, applications, and networks.

## Examples

```text
Vulnerability Assessment
        ↓
Identify & Prioritize Weaknesses
        ↓
Penetration Testing
        ↓
Safely Validate Exploitability
        ↓
Report & Remediate Findings
```

Common tools:

- Nmap → Network discovery and service enumeration
- Nessus → Vulnerability scanning
- Burp Suite → Web application security testing
- OWASP ZAP → Web application security testing

## Characteristics

- **Vulnerability Assessment** → Identifies and prioritizes potential weaknesses
- **Penetration Testing** → Attempts to validate whether weaknesses can be exploited
- Findings are documented with evidence and risk ratings
- Remediation may include patching, configuration changes, or access restrictions
- Testing must be performed only with proper authorization and within the agreed scope

## Key Takeaway

**Vulnerability Assessment → Find and prioritize weaknesses.**

**Penetration Testing → Safely test whether weaknesses can be exploited.**
