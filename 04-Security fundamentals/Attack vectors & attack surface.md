# 🎯 Attack Vectors & Attack Surface

An attack vector is the method or path an attacker uses to reach a target. Attack surface is the total number of possible points that could be targeted.

## Examples

Common attack vectors:

```text
Phishing
Malware
Weak Passwords
Unpatched Software
Exposed Services
Insider Access
```

Example:

```text
Internet
   ↓
Exposed RDP
   ↓
Weak Password
   ↓
Unauthorized Access
```

## Characteristics

- **Attack Vector** → Method used to perform an attack
- **Attack Surface** → All possible entry points into a system
- Exposed ports and services can increase attack surface
- Unpatched software can create exploitable entry points
- Reducing unnecessary exposure reduces attack surface

## Key Takeaway

**Attack Vector → How an attacker gets in.**  
**Attack Surface → All the possible ways an attacker could get in.**
