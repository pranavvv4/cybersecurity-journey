# 🔑 Password Security

Password security involves creating, storing, and managing passwords safely to prevent unauthorized access to accounts and systems.

## Examples

```text
Weak Password      → password123
Strong Password    → Long, unique passphrase
Password Reuse     → Same password across multiple accounts
Credential Stuffing → Using leaked credentials on other services
```

## Characteristics

- Use long, unique passwords for each account
- Use a password manager to generate and store passwords
- Enable Multi-Factor Authentication (MFA)
- Avoid sharing passwords or storing them in plain text
- Services should store passwords using dedicated password-hashing algorithms such as Argon2id, bcrypt, or scrypt
- Monitor for compromised credentials and change affected passwords

## Key Takeaway

**Password Security → Protect accounts using unique passwords, secure storage, and additional authentication factors.**
