# 🎯 Security Controls

Security controls are safeguards used to prevent, detect, or reduce the impact of security threats.

## Examples

```text
Preventive → Firewall
Detective  → SIEM
Corrective → Backup / Recovery
```

Other examples:

- Multi-factor authentication (MFA)
- Antivirus / Endpoint Protection
- Access controls
- Security policies
- Network segmentation

## Characteristics

- **Preventive** → Stops or reduces an attack before it causes harm
- **Detective** → Identifies suspicious activity or security incidents
- **Corrective** → Helps restore systems after an incident
- Controls can be technical, administrative, or physical
- Multiple controls can be combined for defense in depth

## Key Takeaway

**Security Controls → Safeguards used to prevent, detect, and respond to security risks.**
