# 🦠 Common Attack Types

Common attack types are methods attackers use to compromise systems, accounts, networks, or data.

## Examples

```text
Phishing      → Tricks users into revealing information
Malware       → Malicious software
Brute Force   → Repeatedly attempts passwords
DoS / DDoS    → Disrupts service availability
MITM          → Intercepts communication
Ransomware    → Encrypts data and demands payment
```

## Characteristics

- **Phishing** → Uses deception to target users
- **Malware** → Uses malicious software to perform harmful actions
- **Brute Force** → Attempts many possible credentials
- **DoS/DDoS** → Overwhelms a service with traffic or requests
- **MITM** → Intercepts communication between parties
- **Ransomware** → Encrypts or locks data and demands payment

## Key Takeaway

**Attack Types → Different techniques attackers use to compromise systems, users, networks, or data.**
