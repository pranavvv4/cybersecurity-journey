# 🛡️ Zero Trust Security

Zero Trust is a security model based on the principle of never automatically trusting a user, device, or connection simply because it is inside a network.

## Examples

```text
User Requests Access
        ↓
Verify Identity
        ↓
Check Device & Context
        ↓
Evaluate Permissions
        ↓
Grant Limited Access
        ↓
Continuously Monitor
```

## Characteristics

- **Verify Explicitly** → Authenticate and evaluate each access request
- **Least Privilege** → Grant only the access required
- **Assume Breach** → Design security to limit damage if an attacker gains access
- Uses identity, device health, and contextual signals
- Supports segmentation and continuous monitoring
- Applies to on-premises, cloud, and hybrid environments

## Key Takeaway

**Zero Trust → Explicitly verify access, enforce least privilege, and assume a breach may occur.**
