# 🪪 Identity & Access Management (IAM)

Identity and Access Management (IAM) is the process of managing digital identities and controlling who can access systems, applications, and resources.

## Examples

```text
User Identity → Authentication → Authorization → Resource Access
```

Example:

```text
Employee → Login with MFA → Role Checked → Access Granted
```

## Characteristics

- **Identity Management** → Creates and manages user identities
- **Authentication** → Verifies identity
- **Authorization** → Determines permitted actions
- **Access Control** → Enforces access permissions
- **RBAC** → Assigns permissions based on roles
- **Least Privilege** → Grants only necessary access
- IAM applies to on-premises systems and cloud environments

## Key Takeaway

**IAM → Manages identities and controls access to resources.**
