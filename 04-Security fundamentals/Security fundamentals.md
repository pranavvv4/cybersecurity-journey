# 🛡️ Security Fundamentals

Cybersecurity is the practice of protecting systems, networks, applications, and data from unauthorized access, misuse, disruption, or destruction.

## Examples

Common security goals:

```text
Confidentiality → Prevent unauthorized access
Integrity       → Prevent unauthorized modification
Availability    → Keep systems and data accessible
```

Common security concepts:

```text
Threat → Potential cause of harm
Vulnerability → Weakness that can be exploited
Risk → Potential impact of a threat exploiting a vulnerability
Attack → Attempt to exploit a weakness
Control → Measure used to reduce risk
```

## Characteristics

- **Confidentiality** → Only authorized users can access information
- **Integrity** → Information remains accurate and trustworthy
- **Availability** → Systems and data remain accessible when needed
- Security involves prevention, detection, response, and recovery
- Security controls can be technical, administrative, or physical

## Key Takeaway

**Cybersecurity → Protect systems and information by reducing risks and maintaining confidentiality, integrity, and availability.**
