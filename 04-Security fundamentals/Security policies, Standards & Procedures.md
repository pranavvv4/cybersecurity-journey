# 🧾 Security Policies, Standards & Procedures

Security policies, standards, and procedures define how an organization protects its systems, data, and resources.

## Examples

```text
Policy    → What must be achieved
Standard  → Mandatory security requirements
Procedure → Steps to perform a task
Guideline → Recommended practices
```

Example:

```text
Policy    → Protect company accounts
Standard  → MFA is required
Procedure → Steps to enroll in MFA
Guideline → Use a password manager
```

## Characteristics

- **Policy** → Defines security objectives and organizational expectations
- **Standard** → Specifies mandatory requirements
- **Procedure** → Provides step-by-step instructions
- **Guideline** → Offers recommended practices
- Helps establish consistent security practices
- Supports compliance and risk management

## Key Takeaway

**Policy → What and why.**  
**Standard → Required rules.**  
**Procedure → How to do it.**  
**Guideline → Recommended approach.**
