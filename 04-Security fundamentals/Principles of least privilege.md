# 🔑 Principle of Least Privilege

The Principle of Least Privilege (PoLP) means giving users, applications, and processes only the permissions necessary to perform their tasks.

## Examples

```text
Employee → Access only required files
Web App   → Use a restricted service account
Admin     → Use elevated privileges only when needed
```

## Characteristics

- Limits unnecessary permissions
- Reduces the impact of compromised accounts
- Helps prevent unauthorized access
- Applies to users, applications, services, and cloud resources
- Supports stronger access control
- Works alongside role-based access control (RBAC)

## Key Takeaway

**Least Privilege → Give only the minimum permissions required to perform a task.**
