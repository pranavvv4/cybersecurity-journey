# 📋 Security Audits & Compliance

A security audit evaluates an organization's systems, policies, and controls to determine whether security requirements are being met. Compliance means following applicable laws, regulations, standards, and contractual requirements.

## Examples

Common security frameworks and standards:

```text
ISO 27001  → Information Security Management System
NIST CSF   → Cybersecurity risk management framework
PCI DSS   → Payment card data security
GDPR      → Personal data protection regulation
```

## Characteristics

- **Security Audit** → Examines security controls and supporting evidence
- **Compliance** → Determines whether applicable requirements are satisfied
- **ISO 27001** → Provides requirements for an Information Security Management System (ISMS)
- **NIST CSF** → Organizes cybersecurity outcomes into six Functions: Govern, Identify, Protect, Detect, Respond, and Recover
- **PCI DSS** → Applies to environments that store, process, or transmit payment card data
- **GDPR** → Establishes data protection requirements for organizations within its scope

## Key Takeaway

**Security Audit → Evaluates security controls.**

**Compliance → Demonstrates adherence to applicable requirements.**
