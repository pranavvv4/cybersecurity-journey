# 🔐 Multi-Factor Authentication (MFA)

Multi-Factor Authentication (MFA) requires users to verify their identity using two or more different types of authentication factors.

## Examples

```text
Password + Authenticator App
Password + Security Key
PIN + Fingerprint
```

Authentication factors:

```text
Something you know      → Password or PIN
Something you have     → Phone or Security Key
Something you are      → Fingerprint or Face
```

## Characteristics

- Adds an extra layer of security beyond passwords
- Uses different categories of authentication factors
- Helps protect accounts if a password is stolen
- Authenticator apps and hardware security keys can provide stronger protection
- Two passwords alone do not count as two different factors

## Key Takeaway

**MFA → Requires two or more different authentication factors to verify identity.**
